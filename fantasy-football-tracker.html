External team news check

This app has no live source for team news or predicted lineups — FPL's API doesn't expose it, and the free websites that do don't offer a public API. Generate a prompt below, run it in a fresh chat (Claude, ChatGPT, or Gemini — whichever you use), let it search the web for current team news on your flagged players and give its own starting-XI opinion, then paste its JSON reply back in to import it here. Genuinely informs the Advice tab's starting-XI and captain choices where a confident signal exists — see the "External advice considered" note there for exactly what, if anything, was adjusted.
