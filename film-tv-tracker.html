History & Watchlist Import
Three ways to bulk-populate the library. All of them match against TMDB, merge into anything already here rather than duplicating (a viewing-history import will flip an existing watchlist title to watched, never add a second entry; a watchlist import never downgrades something already watched), and add whatever TMDB can't match as a plain flagged entry rather than dropping it. Large imports run one TMDB lookup at a time and can take a while — progress and Cancel show below once started.
JSON format for the last two: either a plain array, or {"titles":[…]}. Each item can be just a title string, or {"title":"…","year":2020,"type":"movie"} ("type" is "movie" or "tv", both optional — a year narrows an ambiguous title, a type skips guessing film vs TV).
Library Maintenance
Checks every TV show already in your library against TMDB for a season count it doesn't know about yet. A flagged show gets a NEW badge on its poster and appears in the New seasons row on the Library, since a show you've finished can still get a new season. This doesn't change anything by itself; open the flagged title's Episodes & Seasons section to update its tracked season count when you're ready.
A fresh device (a new phone, a cleared browser, a first-time open before shared sync existed) seeds the 12 default streaming services locally with brand-new IDs. If those got synced up before this was fixed, the same service can exist more than once — this finds every duplicate group by name, keeps one record per name (favouring one with access ticked, then one with notes, then the most recently updated), carries over any access/notes the others had, and removes the rest.
