History & Watchlist Import
Three ways to bulk-populate the library. All of them match against TMDB, merge into anything already here rather than duplicating (a viewing-history import will flip an existing watchlist title to watched, never add a second entry; a watchlist import never downgrades something already watched), and add whatever TMDB can't match as a plain flagged entry rather than dropping it. Large imports run one TMDB lookup at a time and can take a while — progress and Cancel show below once started.
JSON format for the last two: either a plain array, or {"titles":[…]}. Each item can be just a title string, or {"title":"…","year":2020,"type":"movie"} ("type" is "movie" or "tv", both optional — a year narrows an ambiguous title, a type skips guessing film vs TV).
Library Maintenance
Checks every TV show already in your library against TMDB for a season count it doesn't know about yet. A flagged show gets a 🆕 badge on its card and shows up in a Dashboard section — in either Watchlist or Watched, since a show you've finished can still get a new season. This doesn't change anything by itself; open the flagged title's Episodes & Seasons section to update its tracked season count when you're ready.
