Import Titles
Bulk-add titles from a list. Each one is matched against TMDB, and anything already in your library is left alone rather than duplicated. Whatever TMDB can't match is still added as a plain flagged entry rather than dropped. Large imports run one TMDB lookup at a time and can take a while; progress and Cancel show below once started.
A CSV with a header row, or JSON. Fields, in order of how much they help TMDB match: tmdb_id (needs type) or imdb_id (like tt0113277) match exactly; otherwise title (required) with year and type (movie or tv). Example CSV header: title,year,type,imdb_id. JSON: an array of strings or of objects using the same field names. Titles already in your library are left alone. Everything new arrives untagged, and the tagging window opens when the import finishes; if you can't finish, reopen it from the Tag imported titles button and only the untagged ones remain.
🤖 Have an AI write the list for you
Paste this prompt into any AI chat, replace the last line with your list (notes, a copied column, a description like “the best-reviewed sci-fi films of the 2010s”), and save its reply as a .json or .txt file. Then choose that file with Title list above. The prompt asks for title, year and type only, and leaves out IDs on purpose: an AI often guesses an ID wrongly, and a wrong ID would import the wrong title.
Library Maintenance
Checks every TV show already in your library against TMDB for a season count it doesn't know about yet. A flagged show gets a NEW badge on its poster and appears in the New seasons row on the Library, since a show you've finished can still get a new season. This doesn't change anything by itself; open the flagged title's Episodes & Seasons section to update its tracked season count when you're ready.
A fresh device (a new phone, a cleared browser, a first-time open before shared sync existed) seeds the 12 default streaming services locally with brand-new IDs. If those got synced up before this was fixed, the same service can exist more than once — this finds every duplicate group by name, keeps one record per name (favouring one with access ticked, then one with notes, then the most recently updated), carries over any access/notes the others had, and removes the rest.
